# Codeforces (C++)

My personal solutions to problems from [Codeforces](https://codeforces.com) implemented in C++. This repository serves as a place to practice C++ and various competitive programming techniques.

You can view my Codeforces profile [here](https://codeforces.com/profile/luka98122).

---

## Repository Structure

```text
.
├── LiveContests/        # Solutions from official, real-time rounds
├── Problemset/          # Standalone problems from the general pool
│   ├── 160A/
│   │   └── main.cpp
│   └── ...
└── VirtualContests/     # Past contests simulated under contest conditions
```

**LiveContests/**:
Solutions written during official live rounds hosted by Codeforces, which typically occur once or twice a week.

**VirtualContests/**:
Solutions from past official rounds completed as "Virtual Contests" to simulate real-time competition constraints and practice time management.

**Problemset/**:
Individual practice problems sourced directly from the Codeforces Problemset. Each problem is isolated in its own directory containing the C++ source code (main.cpp) and its compiled executable.
